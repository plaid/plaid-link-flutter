# Plaid Link Flutter Example

Demonstrates how to use the official `plaid_link_flutter` plugin.

The app mirrors the React Native example visually and includes screens for:

- Plaid Link Session
- Plaid Layer Session
- Plaid Headless Session
- Plaid Embedded Search
- Sync FinanceKit

## Running

```sh
flutter run
```

Paste a link token generated by your backend, create the session for the flow
you want to test, and then open or start it from the screen.

FinanceKit is iOS-only. Android displays the unsupported-platform API error.

## Getting Test Tokens

The example app does not create link tokens. Create tokens from your backend
using Plaid's `/link/token/create` endpoint, then paste the returned
`link_token` into the screen you want to test.

Use a token that matches the flow:

- Plaid Link Session: regular Link token.
- Plaid Layer Session: Layer-compatible token.
- Plaid Headless Session: Headless-compatible token.
- Plaid Embedded Search: Embedded-compatible token.
- Sync FinanceKit: FinanceKit-compatible token associated with an eligible Item.

## Screen Guide

### Plaid Link Session

Paste a regular link token, tap create, then tap open. Use this for the standard
bank-linking smoke test. Success, exit, and event payloads appear in the result
area.

### Plaid Layer Session

Paste a Layer token, tap create, optionally enter phone number, date of birth,
or params, then submit and open. A regular Link token will not work for this
screen.

### Plaid Headless Session

Paste a Headless token, tap create, then start the session. Headless flows are
programmatic and do not show the same full Link UI as regular Link.

### Plaid Embedded Search

Paste an Embedded Search token and render the view. The screen shows embedded
load, success, exit, and event callbacks. On Android, keep one embedded view
mounted at a time.

### Sync FinanceKit

Use iOS 17.4 or later. Live sync requires the Apple FinanceKit entitlement and a
real eligible device/account setup. Android intentionally shows the
`UNSUPPORTED_ANDROID` API error.

## OAuth Testing

Use a token configured with the same redirect URI you plan to ship. On iOS,
verify the Universal Link domain association for that redirect URI. On Android,
verify the package name and app link/deep link handling. This Flutter SDK does not configure
`plaidlink://complete` and does not expose `resumeAfterTermination`; native Link
SDK OAuth continuation depends on your Plaid Dashboard redirect settings and
the host app's Universal Link or Android app configuration.

Test OAuth on a real device before release. Simulators are useful for basic Link
flows, but they do not fully prove app-switching behavior.
