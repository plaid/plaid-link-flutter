# Plaid Link Flutter Example

Demonstrates how to use the official `plaid_link_flutter` plugin.

The app mirrors the React Native example visually and includes screens for:

- Plaid Link Session
- Plaid Layer Session
- Plaid Headless Session
- Plaid Embedded Search
- Sync FinanceKit

## Running

```sh
flutter run
```

Paste a link token generated by your backend, create the session for the flow
you want to test, and then open or start it from the screen.

FinanceKit is iOS-only. Android displays the unsupported-platform API error.
