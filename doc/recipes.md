# Plaid Link Flutter Recipes

These examples are intentionally minimal and copy-paste friendly. Replace
`linkToken` with a token generated by your backend using Plaid's
`/link/token/create` endpoint.

## Regular Link

```dart
import 'package:plaid_link_flutter/plaid_link_flutter.dart';

PlaidLinkSession? _session;
bool _ready = false;

Future<void> createLink(String linkToken) async {
  _session = await createPlaidLinkSession(
    LinkTokenConfiguration(
      token: linkToken,
      onSuccess: (success) {
        print('public token: ${success.publicToken}');
      },
      onExit: (exit) {
        print('exit: ${exit.error?.errorMessage}');
      },
      onEvent: (event) {
        print('event: ${event.eventName}');
      },
      onLoad: () {
        setState(() => _ready = true);
      },
    ),
  );
}

Future<void> openLink() async {
  if (!_ready) return;
  await _session?.open();
}
```

Use fullscreen presentation on iOS by passing `true`:

```dart
await _session?.open(true);
```

## Layer Submit

Use a Layer-compatible token. Create the session, optionally submit user data,
then open Layer.

```dart
PlaidLayerSession? _layerSession;

Future<void> createLayer(String layerToken) async {
  _layerSession = await createPlaidLayerSession(
    LayerTokenConfiguration(
      token: layerToken,
      onSuccess: (success) {
        print(success.publicToken);
      },
      onExit: (exit) {
        print(exit.error?.errorMessage);
      },
      onEvent: (event) {
        print(event.eventName);
      },
    ),
  );
}

Future<void> submitAndOpenLayer() async {
  await _layerSession?.submit(
    const SubmissionData(
      phoneNumber: '+15551234567',
      dateOfBirth: '1990-01-31',
      params: <String, String>{'source': 'flutter'},
    ),
  );
  await _layerSession?.open();
}
```

## Headless

Use a Headless-compatible token. Headless does not present the standard Link UI;
start it when your app is ready.

```dart
PlaidHeadlessSession? _headlessSession;
bool _headlessReady = false;

Future<void> createHeadless(String linkToken) async {
  _headlessSession = await createPlaidHeadlessSession(
    LinkTokenConfiguration(
      token: linkToken,
      onSuccess: (success) {
        print(success.publicToken);
      },
      onExit: (exit) {
        print(exit.error?.errorMessage);
      },
      onEvent: (event) {
        print(event.eventName);
      },
      onLoad: () {
        setState(() => _headlessReady = true);
      },
    ),
  );
}

Future<void> startHeadless() async {
  if (!_headlessReady) return;
  await _headlessSession?.start();
}
```

## Embedded Search

Embedded Search is mobile-only. Put the platform view in a fixed-size parent.

```dart
SizedBox(
  height: 420,
  child: PlaidEmbeddedSearchView(
    token: linkToken,
    onSuccess: (success) {
      print(success.publicToken);
    },
    onExit: (exit) {
      print(exit.error?.errorMessage);
    },
    onEvent: (event) {
      print(event.eventName);
    },
    onLoad: () {
      print('embedded search loaded');
    },
  ),
);
```

On Android, keep only one active embedded search view mounted at a time.

## FinanceKit Sync

FinanceKit is iOS-only. It requires iOS 17.4 or later. Live sync requires the
Apple FinanceKit entitlement.

```dart
try {
  await syncFinanceKit(
    FinanceKitConfiguration(
      token: linkToken,
      requestAuthorizationIfNeeded: true,
      syncBehavior: FinanceKitSyncBehavior.live,
    ),
  );
} on FinanceKitException catch (error) {
  print('${error.code}: ${error.message}');
}
```

Use simulated behavior where appropriate during development:

```dart
await syncFinanceKit(
  FinanceKitConfiguration(
    token: linkToken,
    syncBehavior: FinanceKitSyncBehavior.simulated,
  ),
);
```

## Android FinanceKit Guard

Android returns `UNSUPPORTED_ANDROID` for FinanceKit. Gate calls in your app UI
or handle the error:

```dart
try {
  await syncFinanceKit(FinanceKitConfiguration(token: linkToken));
} on FinanceKitException catch (error) {
  if (error.code == 'UNSUPPORTED_ANDROID') {
    print('FinanceKit is only available on iOS.');
    return;
  }
  rethrow;
}
```

## Lifecycle Pattern

Create at most one non-embedded session at a time:

```dart
PlaidLinkSession? _linkSession;

Future<void> recreate(String linkToken) async {
  _linkSession = await createPlaidLinkSession(
    LinkTokenConfiguration(
      token: linkToken,
      onSuccess: (_) {},
      onExit: (_) {},
      onEvent: (_) {},
    ),
  );
}
```

Calling `createPlaidLinkSession`, `createPlaidLayerSession`, or
`createPlaidHeadlessSession` replaces the previous non-embedded callback set.
After success or exit, the SDK cleans up the active callbacks.
