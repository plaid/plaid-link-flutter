# API Reference

This document summarizes the public Dart API and payload model shapes. Pub.dev
also generates Dart API documentation from this package after release. Locally,
run:

```sh
dart doc
```

## Public Methods

| API | Returns | Description |
| --- | --- | --- |
| `createPlaidLinkSession(LinkTokenConfiguration config)` | `Future<PlaidLinkSession>` | Creates a regular Link session. |
| `PlaidLinkSession.open([bool fullScreen = false])` | `Future<void>` | Opens the regular Link session. |
| `createPlaidLayerSession(LayerTokenConfiguration config)` | `Future<PlaidLayerSession>` | Creates a Layer session. |
| `PlaidLayerSession.open()` | `Future<void>` | Opens the Layer session. |
| `PlaidLayerSession.submit(SubmissionData data)` | `Future<void>` | Submits user-collected data to Layer. |
| `createPlaidHeadlessSession(LinkTokenConfiguration config)` | `Future<PlaidHeadlessSession>` | Creates a Headless session. |
| `PlaidHeadlessSession.start()` | `Future<void>` | Starts the Headless session. |
| `syncFinanceKit(FinanceKitConfiguration config)` | `Future<void>` | Runs iOS FinanceKit sync. Android throws `FinanceKitException`. |
| `PlaidLink.sdkVersion` | `Future<String?>` | Returns the native Plaid SDK version, not the Flutter package version. |
| `PlaidLink.onEvent` | `Stream<LinkEvent>` | Process-wide event stream for advanced observers. Prefer per-session callbacks. |

## Configuration Types

### `LinkTokenConfiguration`

| Field | Type | Nullable | Notes |
| --- | --- | --- | --- |
| `token` | `String` | No | Link token generated by your backend. |
| `onSuccess` | `void Function(LinkSuccess)` | No | Terminal callback. |
| `onExit` | `void Function(LinkExit)` | No | Terminal callback. |
| `onEvent` | `void Function(LinkEvent)` | No | Non-terminal callback. |
| `onLoad` | `void Function()` | Yes | Called after native create/load completes. |

### `LayerTokenConfiguration`

| Field | Type | Nullable | Notes |
| --- | --- | --- | --- |
| `token` | `String` | No | Layer-compatible link token. |
| `onSuccess` | `void Function(LinkSuccess)` | No | Terminal callback. |
| `onExit` | `void Function(LinkExit)` | Yes | Terminal callback. |
| `onEvent` | `void Function(LinkEvent)` | Yes | Non-terminal callback. |

### `EmbeddedLinkTokenConfiguration`

| Field | Type | Nullable | Notes |
| --- | --- | --- | --- |
| `token` | `String` | No | Embedded-compatible link token. |
| `onSuccess` | `void Function(LinkSuccess)` | No | Terminal callback. |
| `onExit` | `void Function(LinkExit)` | Yes | Terminal callback. |
| `onEvent` | `void Function(LinkEvent)` | Yes | Non-terminal callback. |

This type is available for parity with the native/RN API shape. The Flutter
widget currently takes the token and callbacks directly.

### `PlaidEmbeddedSearchView`

| Constructor argument | Type | Nullable | Notes |
| --- | --- | --- | --- |
| `token` | `String` | No | Embedded-compatible link token. |
| `onSuccess` | `void Function(LinkSuccess)` | Yes | Terminal callback. |
| `onExit` | `void Function(LinkExit)` | Yes | Terminal callback. |
| `onEvent` | `void Function(LinkEvent)` | Yes | Non-terminal callback. |
| `onLoad` | `void Function()` | Yes | Called when the embedded view loads. |

## FinanceKit

### `FinanceKitConfiguration`

| Field | Type | Nullable | Default |
| --- | --- | --- | --- |
| `token` | `String` | No | None |
| `requestAuthorizationIfNeeded` | `bool` | No | `true` |
| `syncBehavior` | `FinanceKitSyncBehavior` | No | `FinanceKitSyncBehavior.live` |

### `FinanceKitSyncBehavior`

| Value | Native value |
| --- | --- |
| `FinanceKitSyncBehavior.live` | `0` |
| `FinanceKitSyncBehavior.simulated` | `1` |

### `FinanceKitException`

| Field | Type | Nullable |
| --- | --- | --- |
| `type` | `FinanceKitErrorType` | No |
| `code` | `String` | No |
| `message` | `String` | No |

### `FinanceKitErrorType`

| Value | Mapped platform code |
| --- | --- |
| `FinanceKitErrorType.invalidToken` | `INVALID_TOKEN` |
| `FinanceKitErrorType.permissionError` | `PERMISSION_ERROR` |
| `FinanceKitErrorType.linkApiError` | `LINK_API_ERROR` |
| `FinanceKitErrorType.permissionAccessError` | `PERMISSION_ACCESS_ERROR` |
| `FinanceKitErrorType.unknown` | Any other code, including platform support errors. |
